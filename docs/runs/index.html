Why Each Row Shows a Cost

Every run spends model money, so a price per run decides whether FirstRun can be sold. neatlogs measures the cost of each run. cfo.ai turns those costs into 18 months of cash, and the model showed that the old $0.50 cap per run could end the company in month 14. The plan now sets the cap: $0.0471 for a Team run and $0.028 for a Scale run. Runs before that change had no cap.
