Find the Docs Your Product Outgrew.

A docs audit reads your repo's git history. It ranks every page by age, flags the pages your code changed underneath, finds shipped features that no page names, and drafts the release notes.

The audit runs on your machine with one blobless clone. It reads text and history, so it costs $0 in model calls. Jev sorts commits that have no conventional prefix, if a key is set.

Stale, not just oldA page is stale when product commits on its topic landed after its last edit. An old page nobody's code touched is quiet.
Features with no docsEvery user-facing commit in 120 days is checked against the docs text. A flag or a name no page mentions becomes a card.
Work done for youRelease notes for the newest tag and product highlights, drafted from commits and pull requests, ready to edit.
