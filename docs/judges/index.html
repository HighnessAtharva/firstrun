  1. Planning

    Claude turns the docs page into a runbook and copies each command exactly.

  2. Tool use

    classify.pyone TOOL span per call
  3. State

    state.json is written after every step, so firstrun run --resume RUN_ID picks up a stopped run.

    state.py
  4. Context

    The planner reads only the quickstart page.

    planner.pyread_docs TOOL span
  5. Execution

    One fresh container per run, with the exit code on every step.

    executor.pystep.N TOOL span
  6. Recovery

    Classify, search, patch and retry, at most 3 times per step.

    recovery.pyrecover.N AGENT span
  7. Verification

    A second clean container reruns the patched steps with model calls blocked.

    verify.pyverify GUARDRAIL span

Two Commands Install FirstRun and Run a Quickstart

Install and run
$ pip install git+https://github.com/HighnessAtharva/firstrun
$ firstrun https://docs.example.com/quickstart

A run needs Python 3.11 or newer, Git, Docker and a Claude token in CLAUDE_CODE_OAUTH_TOKEN. README quickstart

Run the offline tests, no network, Docker or keys
$ git clone https://github.com/HighnessAtharva/firstrun
$ cd firstrun && pip install -e ".[dev]" && pytest -q

The README badge records 360 offline tests. A run on the launch branch on 2026-10-11 passed 360, skipped 65 that need FIRSTRUN_LIVE=1 or a human check, and had 1 expected failure. GitHub Actions
